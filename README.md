# Rome Air Quality Index Predictor

In the latest times, with the environmental conditions being a cause of concern for global wellness and biodiversity preservation, the Air Quality Index measurement has been taken seriously into consideration. Recent AQI data indicates that air pollution is no longer limited to major industrial or metropolitan cities. Surprisingly, smaller towns and coastal regions are also appearing on the list of highly polluted locations.

Our project deploys a prediction pipeline for the European AQI standard for Rome by using
AWS Lambda, delivering real-time performance on CPU-only
infrastructure through the use of cross-framework model compilation via the ONNX standard.
We provide an extensive benchmark of both user-oriented
and system-oriented metrics. We utilize the locust testing
framework to simulate realistic user loads in different configurations that allow us to show the vertical and horizontal scaling
capabilities of our cloud-based solution.
